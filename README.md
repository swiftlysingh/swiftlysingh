## Things I've built

- [**RetroBudget**](https://apps.apple.com/us/app/ai-spend-tracker-retrobudget/id6743363764)
  An AI spend tracker for iPhone with paying subscribers. Import a credit-card statement PDF and see your month by category, no bank login.

- [**Holder**](https://github.com/swiftlysingh/Holder) · [App Store](https://apps.apple.com/us/app/offline-card-vault-holder/id6475649492)
  An offline card vault for iPhone, secured with Keychain and Face ID.

- [**excalidraw-cli**](https://github.com/swiftlysingh/excalidraw-cli)
  Turns text, JSON or Graphviz DOT into editable Excalidraw diagrams. 300+ stars; Gas City and Beads use it for their docs.

- [**Pitlane**](https://www.linkedin.com/feed/update/urn:li:activity:7508661721595691008/) (prototype, demo video)
  Lets cloud coding agents on Linux use Xcode and the iOS Simulator on a remote Mac.

- [**HIGs-PDF**](https://github.com/swiftlysingh/HIGs-PDF)
  Turns Apple's Human Interface Guidelines into one searchable, offline PDF.
